About

Ha-Kyūについて

新しい価値を創り、幸せの輪を広げるグループ。

理念

新しい価値を創り、幸せの輪を広げる。

Ha-Kyūは、身の回りの小さなアイデアから、身近な人の幸せにつながるサービスを素早く創り続けます。
「幸せ」の形はひとつではありません。人それぞれの解釈を尊重しながら、その輪を少しずつ広げていきます。

Mission / Vision / Value

MVV

🎯

Mission

人々が新しい価値に気づき、幸せの輪が広がっていく世界をつくる。

🔭

Vision

私たち自身が新しい価値を創り、最初の幸せの輪を生み出す。

⚙️

Value

身の回りの小さなアイデアから、身近な人の幸せにつながるサービスを、素早く創り続ける。

タグライン：Create values. Let happiness ripple.

Name

「Ha-Kyū」という名前

「ハキュウ」には2つの意味が込められています。

🌊

波及

新しい価値や幸せが、一人のもので終わらず、次の誰かへ広がっていく。
小さな波紋がいつかは大きなうねりになるように、Ha-Kyūのサービスが人から人へと広がることを願っています。

⚡

破急

「序破急」から「序」を抜き、自ら変化を起こして新しい価値を創る。
既存の流れをただ受け入れるのではなく、自分たちの手でその流れを変えるという姿勢です。

Policy

今後の活動方針

📱

身近な課題から始める

大きなテーマではなく、身の回りの「あったらいいな」を起点にサービスを考えます。

🚀

素早くつくり、届ける

完璧を待たずに世に出し、実際のフィードバックをもとに改善し続けます。

🌐

複数のサービスを育てる

Ha-Kyūはオタタビ専用のブランドではありません。将来的に複数のサービスを開発・運営していきます。
